# BUG-002: Новые слоты для оценок не добавляются в электронную ведомость
**Связанный тестовый случай:** TC-010
**ID:** BUG-002  
**Название:** При нажатии кнопки добавления нового слота для оценки новый слот не появляется в ведомости  
**Модуль:** Электронная ведомость оценок  
**Severity:** Critical  
**Priority:** High  
**Тип дефекта:** Functional / UI  
**Статус:** New  
**Окружение:** Windows 10 19045.6456, Chrome 154.0.8037.98

## Предусловия
1. Пользователь авторизован в системе под учётной записью учителя.
2. Открыта электронная ведомость нужного класса и предмета.
3. Пользователю доступна функция добавления новых слотов для оценок.

## Шаги воспроизведения
1. Открыть электронную ведомость.
2. Найти кнопку или действие для добавления нового слота оценки.
3. Нажать кнопку добавления слота.
4. Проверить, появился ли новый слот в таблице.
5. Повторить действие несколько раз и проверить результат.

## Фактический результат
После нажатия кнопки добавления нового слота новый слот в электронной ведомости не появляется. Визуально таблица остаётся без изменений.

## Ожидаемый результат
После нажатия кнопки система добавляет новый слот для оценки в ведомость. Новый слот отображается в таблице и доступен для дальнейшего использования.

## Влияние на пользователя
Учитель не может добавить новые слоты для оценок, что ограничивает возможность вести ведомость и фиксировать результаты учеников.
