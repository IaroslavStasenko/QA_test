
# BUG-001: Таблица ведомости становится нечитаемой при добавлении 20 учеников
**Связанный тестовый случай:** TC-008

**ID:** BUG-001  
**Название:** Таблица электронной ведомости становится нечитаемой при отображении 20 учеников  
**Модуль:** Электронная ведомость  
**Severity:** Major  
**Priority:** High  
**Тип дефекта:** UI / Usability  
**Статус:** New  
**Окружение:** Windows 10 19045.6456, Chrome 154.0.8037.98

## Предусловия
1. Пользователь авторизован в системе.
2. Открыта электронная ведомость выбранного класса.
3. В ведомости отображается список учеников.

## Шаги воспроизведения
1. Открыть электронную ведомость.
2. Добавить в ведомость 20 учеников либо открыть ведомость, в которой уже есть 20 учеников.
3. Дождаться отображения всех записей.
4. Проверить читаемость таблицы: имена учеников, оценки, заголовки столбцов и расположение элементов интерфейса.
5. Попробовать просмотреть данные всех учеников.

## Фактический результат
При отображении 20 учеников таблица становится нечитаемой: данные отображаются слишком плотно, текст или значения оценок могут перекрываться, а структура таблицы затрудняет поиск нужного ученика и просмотр его оценок.

## Ожидаемый результат
При отображении 20 учеников таблица делится на несколько частей и показывается пользователю порционно

## Влияние на пользователя
Учителю становится сложнее находить учеников и проверять оценки. Это повышает риск ошибки при работе с ведомостью и снижает удобство использования системы.
