# Test Cases — Электронная ведомость оценок

| ID | Название тест-кейса | Предусловия | Шаги выполнения | Ожидаемый результат | Приоритет | Тип |
|---|---|---|---|---|---|---|
| TC-001 | Успешное выставление оценки | Учитель авторизован, ведомость открыта | 1. Выбрать класс 7А. 2. Выбрать предмет «Математика». 3. Найти ученика. 4. Ввести оценку 5. 5. Нажать «Сохранить». | Оценка 5 сохранена и отображается у нужного ученика. | High | Positive |
| TC-002 | Проверка сохранения оценки после обновления страницы | Оценка успешно выставлена | 1. Открыть ведомость. 2. Проверить оценку ученика. 3. Обновить страницу. | Ранее сохранённая оценка отображается без изменений. | High | Functional |
| TC-003 | Ввод недопустимой оценки | Учитель авторизован, открыта форма выставления оценки | 1. Выбрать ученика. 2. Ввести значение за пределами допустимого диапазона, например 10, если разрешены только оценки 1–5. 3. Нажать «Сохранить». | Система отклоняет значение, показывает понятное сообщение об ошибке и не сохраняет недопустимую оценку. | High | Negative |
| TC-004 | Редактирование существующей оценки | В ведомости уже есть оценка ученика | 1. Открыть ведомость. 2. Выбрать существующую оценку. 3. Изменить её с 3 на 4. 4. Сохранить изменения. | Новая оценка 4 сохранена и отображается вместо старой оценки 3. | High | Functional |
| TC-005 | Проверка добавления нового ученика | Учитель авторизован, доступна редактирования таблицы | 1. Выбрать таблицу. 2. Добавить пустой слот для ученика поле оценки пустым. 3. Ввести имя ученика. 4. Нажать «Сохранить». | Система сохраняет нового ученика в ведомости. | High | Functioinal |
| TC-006 | Проверка доступа ученика к собственным оценкам | Пользователь авторизован под учётной записью ученика | 1. Открыть раздел оценок. 2. Просмотреть ведомость. | Ученик видит только оценки, доступные для его учётной записи. | High | Funcional |
| TC-007 | Проверка запрета на автроизацию с неправильным паролем | Пользователя нет в базе данных | 1. Попытаться открыть страницу используя несуществующий пароль. | Система не пускает дальше страницы авторизации. | Critical | Negative |
| TC-008 | Проверка на добавление большого количества учеников | В системе есть 15+ учеников | 1. Открыть ведомость. 2. Выбрать класс. 3. Добавить 20-40 учеников. | Ведомость делится на несколько частей и показывается порционно. | Medium | Negative |
| TC-009 | Проверка очистки ведомости по опреденому предмету | Имеется заполненная ведомость по предмету | 1. Открыть ведомость. 2. Открыть нужный предмет. 3. Нажать "Очистить"| Таблица очищена | High | Pozitive |
| TC-010 | Проверка добавления новых слотов для оценок | Имеется заполненная ведомость по предмету | 1. Открыть ведомост. 2. Добавть даты для оценок. 3. Проверить обновленную ведомость. | НОвая ведость содержит пустые даты для оценок. | High | Funcional  |
| TC-011 | Проверка выхода из системы | Пользователь авторизован | 1. Нажать «Выйти». 2. Попытаться открыть защищённую страницу ведомости. | Пользователь выходит из системы; защищённая страница требует повторной авторизации. | High | Funcional  |
| TC-012 | Проверка отображения ведомости для правильного класса | Учитель имеет доступ к нескольким классам | 1. Выбрать класс 7А. 2. Просмотреть список учеников и оценки. | Отображаются данные выбранного класса, без учеников из других классов. | High | Functional |
